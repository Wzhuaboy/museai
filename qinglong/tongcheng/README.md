# 同程旅行里程（yyb-go 版）

同程旅行小程序的里程自动化，Node 脚本，每天跑一次：签到、任务领里程、短剧领奖、钞级省抽奖、多账号互助。

- 脚本：`tongcheng_mileage_yyb.js`（1858 行，2026-10-25 抓包还原）
- 定时：`30 7 * * *`（每天 07:30，脚本头部的 cron）
- 依赖：Node + `axios`
- 登录：不走账号密码，走本地 yyb-go 服务取微信 code 再登录

## 青龙里怎么用

仓库订阅拉取后，在青龙任务里引用这个脚本路径，环境变量在青龙面板里配，不要写进脚本文件。

```
qinglong/tongcheng/tongcheng_mileage_yyb.js
```

先确认 yyb-go 在跑，并且能从青龙所在网络访问到它。

## 环境变量

必填只有 `tclx`，其余都是选填。

| 变量 | 说明 |
| --- | --- |
| `tclx` | 必填，yyb-go 账号标识（ref），多账号用 `&` 或换行分隔，可写 `ref#备注` |
| `yyb_go_url` | 选填，yyb-go 地址，默认是脚本里的内网地址，部署后改成你自己的实际地址 |
| `tclx_schemes` | 选填，任务方案 guid 列表，默认 5 个方案（签到页、会员中心、浏览活动、下拉奖励、客服任务） |
| `tclx_drama_refid` | 选填，短剧活动 refid，默认 `2000615847,2000642046,2001086637` |
| `tclx_dry` | 选填，`true` = 只查余额、签到与任务状态，不签到不领奖 |
| `tclx_help` | 选填，`false` = 关闭多账号互助，默认开启（2 个以上账号才生效） |
| `tclx_pub` | 选填，周周打卡要用的公众号 openid，按 tclx 账号顺序用 `&` 分隔 |
| `tclx_checkin` | 选填，`1` 才自动报名打卡挑战（报名花 100 里程，次日 00:00-14:00 签到才算打卡，默认不报名） |
| `tclx_flower` | 选填，花神总开关，默认 `false`（已关闭） |

## 默认不做的事

- 花神（摇签、翻卡、赠卡、集齐兑换）默认关闭，`tclx_flower=true` 才恢复。
- 打卡挑战默认不报名，要显式开 `tclx_checkin=1`。
- 钞级省抽奖只播报剩余次数之外的自动抽奖；奖池里的现金和免单额度要好友助力，脚本不替你抽完所有规则。
- 小游戏、客服对话（要真聊一句“花签”）、下拉添加小程序、分享和邀好友类任务，脚本只播报或跳过，不硬做。

## 短剧看剧时长

看剧时长由微信短剧平台服务端统计后回传同程，客户端伪造不了。脚本只自动领访问奖励（+2）和看满后的看剧奖励（+10），时长不够只能真看。

## 不要进仓库的文件

脚本运行时会在同目录生成这两个文件，里面有登录后的 token，只放本地 / 青龙运行目录，不要提交：

```
tclx_token_cache.json
.tclx_gift_state.json
```

仓库的 `.gitignore` 已有 `*token*` 规则，`tclx_token_cache.json` 本身就被拦住了。

## 风险

调的是同程小程序的私有接口，自动化有被风控判定作弊、奖励清零的可能，先用 `tclx_dry=true` 跑一遍看状态，确认没问题再正式跑。
