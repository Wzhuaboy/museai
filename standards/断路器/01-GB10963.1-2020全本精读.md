# GB/T 10963.1-2020 全本精读

- 标准号：GB/T 10963.1-2020《电气附件 家用及类似场所用过电流保护断路器 第1部分：用于交流的断路器》
- 现行状态：现行（2020-11-19 发布，2021-06-01 实施，代替 GB/T 10963.1-2005）
- 采标：等同采用 IEC 60898-1（具体版本有 2015 与 2019 两种说法，见未核实清单）
- 核查日期：2026-11-03
- 来源：openstd.samr.gov.cn（标准状态页）、chinesestandard.net / gb-gbt.com（目录与前言）、codeofchina / antpedia（解读）、IEC 60898-1:2015 样本原文（9.14/9.15/9.16 逐字复核）、TECert 检测项目页、u.dianyuan.com 转载文本（8.4/9.8/9.9/9.11 节选）

## 一、基本信息与适用范围（第 1 章）

- 适用：交流 50Hz、60Hz 或 50/60Hz，额定电压不超过 440V（相间），额定电流不超过 125A，额定短路能力不超过 25000A 的空气式断路器。
- 用途：家用及类似场所的过电流保护；也可用于故障情况下的电击保护（适用范围由安装规程规定）。
- 不适用：电动机保护；不可由非专业人员调节的场合另有规定（见第 4 章分类）。
- 环境：污染等级 2；适合隔离；可用于 IT 系统（2020 版前言新增验证 IT 系统适用性的 9.12.11.2.2 专项试验）。
- 页数：全文约 115 页（不含封面），附录 A-L。

## 三、逐章要点

### 第 2 章 规范性引用文件（已核实部分）

已确认引用：GB/T 5169.10-2017（灼热丝装置和通用试验方法，IEC 60695-2-10:2013 IDT）、GB/T 5169.11-2017（成品灼热丝可燃性试验 GWEPT，IEC 60695-2-11:2014 IDT）。

未核实：完整引用清单是否含 GB/T 5169.5（针焰）、GB/T 5169.21（球压方法）、GB/T 2423.17 / GB/T 10125（盐雾）。目前能查到的引用清单节选里均未见这四本，见未核实清单。

### 第 3 章 术语和定义

核心术语（按 IEC 60898-1 体系）：断路器、额定电流 In、额定电压 Un、额定频率、额定短路能力 Icn、额定运行短路能力 Ics、瞬时脱扣、自由脱扣、接通能力、分断能力、电气间隙、爬电距离、污染等级、隔离。定义本身不展开抄录，检索时按术语原文为准。

### 第 4 章 分类

按极数（1P、2P、3P、4P、1P+N、3P+N）、瞬时脱扣类型（B、C、D）、额定短路能力、接线端子型式（螺纹型、无螺纹型、扁平快速连接型、铝导线用）分类。

- B 型：瞬时脱扣范围 3In-5In，适用于照明、插座等阻性负载。
- C 型：5In-10In，适用于常规配电与一般感性负载。
- D 型：10In-20In，适用于起动电流大的冲击性负载。
- 注意：D 型上限 20In 是 10963.1 的口径；部分厂家资料写 D 型 10In-14In，那是按 GB/T 14048.2 的口径，不要混用。

### 第 5 章 断路器特性

- 额定电流 In 优选值：6、8、10、13、16、20、25、32、40、50、63、80、100、125A（优选值清单待原文复核，见未核实清单）。
- 额定电压 Un：单相 230V、三相 230/400V 等（完整清单待复核）。
- 额定短路能力 Icn 优选值：1500、3000、4500、6000、10000、15000、20000、25000A（待复核）。
- 额定运行短路能力 Ics 与 Icn 的关系（Icn 不大于 6000A 时 Ics 是否等于 Icn 等）待原文复核，不要凭记忆写。
- 5.2.5 单极额定接通和分断能力 Icn1：2020 版新增的额定值要求（见 9.12.11.4.4 多极断路器单极接通和分断能力试验）。
- 额定频率 50Hz、60Hz 或 50/60Hz；基准整定温度 30 度（脱扣特性试验的冷态基准）。

### 第 6 章 标志和其他产品资料

断路器本体应标志：制造商名称或商标、型号、额定电流 In、额定电压、额定频率、瞬时脱扣类型（B/C/D）、额定短路能力 Icn（方框内数字）、接线端子标识、接通/分断位置指示。标志应清晰、耐久（按 9.3 检验）。

### 第 7 章 使用的标准工作条件

- 周围空气温度：-5 度至 +40 度，24h 内平均值不超过 35 度。
- 海拔：不超过 2000m。
- 空气相对湿度：40 度时不超过 50%，较低温度时可较高（如 20 度时 90%）。
- 污染等级 2；安装在 TH35-7.5 型导轨上（模数化安装）。
- 以上为 IEC 60898-1 通用条件口径，GB 版第 7 章逐字表述待复核。

## 四、第 9 章试验逐条精读（试验侧）

### 9.1 总则 / 9.2 试验条件

- 型式试验按附录 C 的试验程序分组进行（程序 A、B、C、D、E 等，试品数量见附录 C）。
- 9.15 灼热丝在 2020 版中独立为程序 A2（前言新增内容）。
- 试验环境温度等通用条件按 9.2；脱扣特性试验以 30 度为基准整定温度（冷态指试验前不带负载）。
- 9.2 通用条件（按 IEC 60898-1 9.2 原文转载复核）：除另有规定外，试验在额定频率 ±5Hz 下、任意方便的电压下进行；未规定允差时，按不低于标准规定值的严酷程度进行；9.8、9.9、9.10、9.11 的接线用单芯 PVC 绝缘铜导线（按 IEC 60227）；除 9.8.2、9.10.2、9.11 外，试验用单相电流、所有极串联通电。

### 9.3 标志耐久性

- 标志用沾水的布擦 15s，再用沾石油溶剂油（petroleum spirit）的布擦 15s，擦后标志仍清晰可读。

### 9.4 螺钉、载流部件和连接的可靠性

- 螺钉按规定力矩拧紧与松开多次（一般 5 次），不应松动、损坏，不应使导体损伤；具体力矩按表 4（数值待原文复核）。

### 9.5 连接外部导体的端子

- 拉力试验与弯曲试验：按导线截面施加拉力与弯曲次数，端子不应松动、导体不应滑出或断裂。

### 9.6 防触电保护试验

- 用标准试指（关节试指）探触：正常使用时不可触及带电部件。

### 9.7 介电性能试验（已按 IEC 60898-1 9.7 原文转载与 2020 版前言复核）

- 9.7.2 工频耐压：试验电压按额定绝缘电压 Ui 计算——Ui 不超过 60V 时为 1000V；Ui 超过 60V 时为 2Ui+1000V，最低 1500V；施加 1min，不应击穿或闪络。常见产品 Ui=500V 时对应 2000V（厂家资料常直接标"介电试验电压 2kV，50/60Hz，1min"），Ui 不同则电压不同，不要把 2000V 当成标准固定值。
- 9.7.5（2020 版调整结构）：包括试验一般要求、耐冲击电压、断开触头之间的泄漏电流、断开触头的绝缘和基本绝缘耐冲击电压能力。
- 9.7.5.1/9.7.6 冲击耐压：1.2/50μs 冲击波，正、负极性各施加 5 次（2020 版由旧版各 3 次改为各 5 次）；同极性冲击间隔至少 1s，异极性间隔至少 10s；试验装置浪涌阻抗标称值 500 欧姆；冲击电压值按表 13、根据表 3 的额定冲击耐受电压选取，并按气压/海拔修正。
- 9.7.5.2：如仅发生一次击穿，可增加施加 10 次冲击电压（2020 版修改）。
- 9.7.5.3 断开触头间的泄漏电流验证：2020 版增加了在 9.12.11.4.4 试验后验证泄漏电流的要求；泄漏电流限值待原文复核。
- 9.7.5.4：正常条件下验证断开触头的绝缘和基本绝缘耐冲击电压能力（对应附录 C 程序 B，CQM 换版通知示例为 Inmax 3 台）。
- 注意：厂家标称的额定冲击耐受电压 Uimp（4kV 或 6kV）和额定绝缘电压 Ui（415V/440V/500V）是产品额定值，随产品而异，不是标准统一规定值；不要把某厂家标称值当成标准值。

### 9.8 温升试验及功耗测量（已按转载原文复核）

- 条件：各极同时通 In，通电至温升稳定（温升变化每小时不超过 1K 即为稳态）或约定时间，两者取较长者；周围空气温度在试验周期最后四分之一时间内测量，温度计/热电偶距断路器约 1m、高度约为断路器高度一半，免受气流和热辐射影响。
- 三保护极的四极断路器：先对三个保护极通电试验，再对中性极与离它最近的保护极通电重复试验。
- 表 5 温升限值（K）：
  - 连接外部导体的接线端子：60
  - 手动操作中断路器过程中容易触及的外部部件（含绝缘操作机构及与其相连的金属部件）：40
  - 操作件的外部金属部件：25
  - 其他外部部件（含断路器与安装平面直接接触的表面）：60
- 注：触头温升不作规定（大部分断路器不拆改部件无法直接测量触头温度）；9.9 的 28 昼夜试验被认为已间接考核触头。
- 功耗测量与温升试验同条进行（具体方法待复核）。

### 9.9 28 昼夜试验

- 28 个试验周期，每周期：通额定电流 21h + 不通电流 3h；断路器处于闭合位置，用辅助开关接通和断开电流；开路电压至少 30V。
- 试验过程中断路器不应脱扣；在最后一个通电时间内测量接线端子温升。
- 试验结束后验证瞬时脱扣：按转载文本，断路器应在 0.1s 内脱扣（具体试验电流与条款衔接待原文复核）。

### 9.11 机械和电气寿命试验

- 在额定电流下经受 4000 次循环操作，每循环包括一次接通和紧接着的一次分断。
- In 不大于 32A：每小时 240 次循环，每循环断开位置保持至少 13s。
- In 大于 32A：每小时 120 次循环，每循环断开位置保持至少 28s。
- ~~2020 版新增：对没有规定极性的断路器，一半次数按一个方向接线，一半次数按反方向接线。~~（2026-11-04 他当面纠正：GB/T 10963.1-2020 9.11 原文没有明确写明一半正向、一半反向接线；此前这句来自转载节选，非 GB 原文，作废。待他发 9.11 原文照片后按原文重写，不要再拿这句当标准依据。）
- 无载（机械）操作次数与总循环数待原文复核（IEC 60898-1 另有机械寿命要求，不要把 4000 次当成总寿命）。

### 9.12 短路试验

- 试验电流等级：低电流（500A 或 10In）、1500A、额定短路能力 Icn。
- 操作顺序：O-t-CO、O-t-CO-t-CO 等（按附录 C 程序）；判定：聚乙烯薄膜无可见洞、熔丝不熔断、断路器仍能正常操作。
- 9.12.9.2：额定电压 120V 或 120/240V 的断路器，电阻器 R' 由 7.5 欧姆改为 0.75 欧姆（2020 版修改）。
- 9.12.11.2.2：验证 IT 系统适用性的专项试验（2020 版新增）。
- 9.12.11.4.4：多极断路器单极接通和分断能力试验（2020 版新增，验证 5.2.5 的单极额定接通和分断能力 Icn1），试验后按 9.7.5.3 验证断开触头间的泄漏电流。
- 短路功率因数按附录 A 确定；试验装置按附录 H。

### 9.13 耐机械冲击和撞击试验

- 摆锤冲击 / 跌落试验（按图 10 等），试验后断路器应无影响继续使用的损坏，仍能正常操作。具体冲击能量与次数待原文复核。

### 9.14 耐热试验（球压，已按 IEC 60898-1:2015 原文复核）

- 9.14.1 整机：卸下可移动盖子，(100±2) 度加热箱 1h；可移动盖子 (70±2) 度 1h。试验中不应有影响继续使用的变化，密封化合物不应流失到带电部件外露处；冷却到近室温后，用不超过 5N 的标准试指也不应触及正常不可触及的带电部件；标志仍清晰。
- 9.14.2 必须使载流部件和保护电路部件保持在位的绝缘外部零件：5mm 钢球、20N、(125±2) 度加热箱、1h 后移开钢球、浸冷水 10s 内冷到近室温，压痕直径不应超过 2mm。保护导体接线端子保持在外壳里的绝缘部件按 9.14.3。
- 9.14.3 不必使载流部件保持在位的其他绝缘外部零件：同样方法，温度为 (70±2) 度，或 (40±2) 度加上 9.8 试验期间该部件最高温升，两者取较高者。
- 注：平面安装式断路器基座视为外部零件；陶瓷部件不做 9.14.2/9.14.3；同一材料多个零件只测其中一个。

### 9.15 耐异常发热和耐燃试验（灼热丝，已按 IEC 60898-1:2015 原文复核）

- 方法标准：GB/T 5169.10-2017（装置和通用方法）+ GB/T 5169.11-2017（成品灼热丝可燃性 GWEPT）；整机做，共 3 个样品，施加部位各不相同。
- 温度：必须使载流部件和保护电路部件保持在位的绝缘外部零件 (960±15) 度；所有其他绝缘外部零件 (650±10) 度。
- 不做：陶瓷部件；小零件——每个表面完全落在直径 15mm 圆内，或任何表面上放不下直径 8mm 的圆（见图 17）；同一材料只测一个。
- 不能直接施加的部位：接线端子区域、灭弧室、磁脱扣装置区域——灼热丝伸不进去就触到较大金属件或陶瓷，会迅速冷却灼热丝并限制接触到的绝缘材料量；此时以冷却灼热丝、限制接触来保证最低严酷度。
- 2020 版前言新增：9.15 增加了不需要进行本试验的部分以及灼热丝不能直接施加的部位；9.15 独立为程序 A2。
- 试品取最不利位置（受试表面垂直）；若内部绝缘件导致不合格，可从新样品上拆除该内部件后在同一位置重测；经制造商同意，也可把受试件整体拆下单独试验（按 IEC 60695-2-11 第 4 章）。
- 判定：无可见火焰、无持续火光；或灼热丝移开后火焰/火光在 30s 内自行熄灭；不应点燃薄棉纸、不应烧焦松木板。

### 9.16 防锈试验（用户说的"盐雾"，实为氯化铵法，已按 IEC 60898-1:2015 原文复核）

- 这不是氯化钠盐雾试验（GB/T 2423.17 / GB/T 10125，5% NaCl、35 度盐雾），而是氯化铵防锈试验：
  - 冷化学去油剂（如甲基氯仿或精炼汽油）浸 10min 去油脂；
  - (20±5) 度、10% 氯化铵水溶液浸 10min；
  - 不烘干、抖掉水滴后放进 (20±5) 度饱和水汽空气箱 10min；
  - (100±5) 度烘箱烘 10min 后表面不应有锈蚀迹象。
- 注：锐利边缘锈迹和可擦去的黄斑忽略不计；小弹簧及类似件和不易触及的磨损件涂一层油脂即可提供足够防锈保护，仅在怀疑油膜有效性时才做此试验，且试验前不去除油脂。
- 要求出处：8.12——使用铁合金或适当涂层的铁合金时，用 9.16 试验验证。

## 五、针焰试验：本标准无独立条款

- GB/T 10963.1-2020 正文无独立的针焰试验条款；抽查实施细则对本标准也只列耐热和灼热丝，不列针焰。
- 针焰方法标准本身存在：GB/T 5169.5-2020《电工电子产品着火危险试验 第 5 部分：试验火焰 针焰试验方法 装置、确认试验方法和导则》（IEC 60695-11-5:2016 IDT）；通用做法是 12mm 火焰、施焰后余焰/余灼小于 30s 为合格，但这是方法标准的通用口径，不是本产品标准的规定。
- 背景：GB/T 5169.11-1997 导则称灼热丝可能不适用于表面线性尺寸小于 20mm 的小元件，可用其他试验方法（如针焰试验方法）；IEC 60898-1:2015 的 9.15 全文里没有出现针焰，只写了小零件免做和灼热丝不能直接施加的部位如何处理。
- 结论：针焰不是本标准的型式试验项目，不要硬凑；如需考核小元件着火危险，应按采购规范另行约定方法标准与判定值。

## 七、易混点

1. D 型瞬时脱扣上限 20In 是 10963.1 口径；厂家资料里 D 型 10In-14In 是 GB/T 14048.2 口径，不要混用。
2. 9.16 防锈不是盐雾试验；盐雾试验（GB/T 10125 / GB/T 2423.17 / GB/T 2423.18）是另一组方法标准，本标准未引用。
3. 温升限值是"温升 K"不是"温度 度"：端子 60K 指比周围空气高 60K，不是 60 度。
4. 9.10 表 7 的时间极限分 In 不大于 63A / 大于 63A、In 不大于 32A / 大于 32A 两档，不要只记一档。
5. 9.14.2 的 125 度球压只针对"必须使载流部件和保护电路部件保持在位"的零件；其他零件按 9.14.3（70 度或 40 度+温升取高者）。
6. 灼热丝 960 度只针对保持载流/保护电路部件在位的零件；其他绝缘外部零件是 650 度。
