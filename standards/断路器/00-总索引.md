## 五、最重要的三条纠正（永久生效）

1. 防锈不是盐雾：三本断路器标准的防锈试验都是 10% 氯化铵法（去油脂浸 10min → (20±5)℃ 10% 氯化铵浸 10min → 饱和水汽 10min → (100±5)℃ 烘 10min、无锈蚀）。盐雾试验（GB/T 10125 / 2423.17 / 2423.18）是另一组方法标准，三本产品标准均未引用它；盐雾只在产品规范另行指定时做。
2. 针焰不是三本的型式试验项目：三本正文均无独立针焰条款；方法标准 GB/T 5169.5-2020 本身存在，但不要硬凑进产品标准。第 2 章引用清单里也未见 GB/T 5169.5。
3. 条款号全线错位，不要跨本套用：冲击、耐热、灼热丝、防锈、寿命、短路、动作特性在三本里的条款号各不相同（见第三节对照表）；温升端子限值 10963.1 是 60K、16916.1 / 16917.1 是 65K；寿命 10963.1 是 4000 次带载、16916.1 / 16917.1 是 2000 次带载 + 无载；D 型 10In-20In 是 10963.1 / 16917.1 口径，GB/T 14048.2 的 D 型口径不同，不要混用。
