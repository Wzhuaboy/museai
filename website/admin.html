小站管理

在这里选哪些项目同步到小站上。开关打开就是同步（在小站上显示），关掉就是不同步（隐藏起来，随时能再打开）。改完点最下面的「保存到 GitHub」才生效。

令牌

怎么建令牌？点开看步骤
  1. 打开 新建细粒度令牌（GitHub 登录状态下直接进）
  2. Token name 随便填，比如 xiaozhan-admin；Expiration 选 90 天
  3. Repository access 选 Only select repositories，勾上 museai
  4. 往下找到 Repository permissions 里的 Contents，选 Read and write
  5. 点 Generate token，复制那串 github_pat_…，只显示一次，贴到上面保存

令牌只存在你这台设备的浏览器里，不会进仓库。别人就算打开这个管理页，没有令牌也保存不了。这个管理页没有放在小站首页上，知道链接才能打开。
